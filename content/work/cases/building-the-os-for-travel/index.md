# Travel ERP Enterprise Platform

A comprehensive enterprise resource planning system redesign focusing on high-density data grids, ergonomic booking matrixes, and strict design token synchronization across design and frontend implementation.

## The Challenge

Travel dispatchers manage hundreds of concurrent itineraries and hotel allocations daily. Legacy tables suffered from visual clutter, poor contrast, and fragile CSS overrides that broke during layout rescaling.

## Architectural Solution

We architected a unified 4px/8px modular design system with semantic OKLCH color tokens, ensuring optimal contrast and readability across dark and light operational environments.
